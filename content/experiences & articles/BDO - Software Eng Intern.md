### Enterprise Chat (BDOChat)
Enterprise chat is a BDO internal ChatGPT application. There are features jam packed into Enterprise Chat such as: document summarization, Sharepoint connections, web search connections, document obligation and summary of terms extractions.
You can create Rooms, upload documents into Rooms, and chat directly with the document. Everything has citations so that you can be certain of it's accuracy.
